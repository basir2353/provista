# ProCareerVista — Next.js

Clone of [procareervista.com](http://procareervista.com/) built with Next.js 15, React, and TypeScript.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home |
| `/about` | About |
| `/pricing` | Pricing |
| `/contact` | Contact |
| `/get-started` | Order form |
| `/templates` | Resume templates |

## Features

- Same design as the live site
- Instant page transitions with progress bar
- Smooth scroll to sections (Industries, Reviews, etc.)
- Scroll reveal + animated stat counters
- Mobile menu with overlay

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build
npm start
```
